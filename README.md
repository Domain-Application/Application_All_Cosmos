# Application_All_Cosmos

Weighbridge program of All Cosmos Industries Sdn Bhd: receiving and despatch weighing of lorries and containers on up to two weighbridge lanes, with header/detail tickets (delivery lines with packing and theoretical weight), licence-plate (LPR) and container-number (CNR) cameras, platform sensors, supervisor sign-in for hand-typed numbers, prime-mover weighing and file-change audit reports. VC6 / MFC on the shared wlib32 framework (project `menu.dsp`). Related program: `Application_Vance_Bioenergy`.
